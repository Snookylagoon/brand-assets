Copies the signature with its formatting and logo.

If the button doesn't work, select the signature by dragging from the start of "Andrew Scott" to the end of the small disclaimer text, then copy it (⌘ C on Mac, Ctrl C on Windows). Copy it from a desktop browser like Chrome, Edge or Safari, not from inside an email.

Computer

Outlook on the web and new Outlook for Windows

  1. Open Settings (the cog, top right) → Account → Signatures.
  2. Click + New signature and name it Hexagon.
  3. Click in the editing box and paste (Ctrl V / ⌘ V).
  4. Under Select default signatures, choose Hexagon for new messages and for replies/forwards, then click Save.

Classic Outlook for Windows

  1. File → Options → Mail → Signatures…
  2. Click New, name it Hexagon and paste into the edit box.
  3. On the right, set New messages and Replies/forwards to Hexagon for your hexagon-holdings.me account, then click OK.

Outlook for Mac

  1. Outlook menu → Settings… → Signatures.
  2. Click +, name it Hexagon, paste into the box and close the editor (it saves when closed).
  3. Under Choose default signature, select your hexagon-holdings.me account and set both New messages and Replies/forwards to Hexagon.

Apple Mail on a Mac

  1. Mail → Settings… → Signatures.
  2. Select your hexagon-holdings.me account in the left column and click +.
  3. Untick “Always match my default message font”, then replace the placeholder text with a paste.
  4. Set Choose Signature to the new one.

Gmail in a browser (only if your hexagon-holdings.me mail is in Gmail)

  1. Settings (cog) → See all settings → General → Signature → Create new.
  2. Paste into the box, set it as the default for new emails and replies, then click Save Changes at the bottom.

Phone and tablet

iPhone / iPad Mail app

  1. Open this page in Safari on the iPhone, tap Copy signature (or press and hold to select it all, then tap Copy).
  2. Go to Settings → Apps → Mail → Signature. On older iOS versions it is Settings → Mail → Signature.
  3. Choose Per Account if you have several, clear your hexagon-holdings.me box and paste.
  4. If the formatting disappears, shake the phone straight after pasting and tap Undo (“Undo Change Attributes”). The formatting comes back.

Outlook app (iPhone and Android)

  1. Tap your profile picture → Settings (cog) → your hexagon-holdings.me account → Signature.
  2. Paste the signature, or type the text version below.

The Outlook mobile app and the Gmail app only keep plain text, so the logo won't show there. If you'd rather not paste, type the text version below.
