Brand Assets

Logos published as PNG for use in HTML email signatures. Each logo is shown on a white and a dark background so you can check that it reads correctly on both. Use the Copy URL button to copy the exact address to paste into your signature.

Never rename, move or delete a published logo. Every email already sent links to its exact address. To update a logo, replace the file under the same name.

Published from the main branch of Snookylagoon/brand-assets via GitHub Pages.
